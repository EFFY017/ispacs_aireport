# iSPACS AIR 报告前端 Demo

基于 `product_requirements/AIR报告编辑与模板能力需求_v1.1.md` 与颅脑编辑界面图实现的纯前端演示项目。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目包含 12 条患者假数据、12 份互不相同且按患者隔离保存的 AIR 报告、12 条 AIR 快捷模板和 15 条 PACS 公共模板数据，以及患者查询、模板搜索、模板插入、所见/诊断关联高亮与非对称删除、一键阴性模板、撤销/重做、重新生成、生成失败后重试、整理报告、查看原始报告等演示交互。

AIR 与 PACS 报告编辑页支持两条独立路径：

- `返回 PACS 编辑`：返回 PACS 编辑界面并保留 PACS 原报告，不插入当前 AIR 内容。
- `引用到 PACS 报告`：直接返回 PACS 编辑界面，并将当前 AIR 影像所见、诊断意见同步至对应编辑框；引用不等于正式发布。
- `整理报告`：将影像所见整理为分号分隔的单段文本；诊断意见使用“序号、诊断内容。”逐条换行展示。
- `撤销 / 重做`：支持在报告编辑操作之间往返；重新生成后的报告同样可撤销并重做。
- `重新生成 / 重试生成`：可主动重新生成当前患者的 AIR 报告；患者“钱*芳”预置为生成失败示例，可从失败提示区或底部按钮重试。
- PACS 顶部 `AI 诊断`：返回当前检查的 AIR 报告并恢复工作草稿。

页面以 1619 × 971 原始界面稿为基准自动等比适配浏览器视口，浏览器保持 100% 缩放即可完整展示全部区域。
