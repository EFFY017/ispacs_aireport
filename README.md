# iSPACS AIR 报告前端 Demo

基于 `product_requirements/AIR报告编辑与模板能力需求_v1.1.md` 与颅脑编辑界面图实现的纯前端演示项目。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目包含 12 条患者假数据、12 份互不相同且按患者隔离保存的 AIR 报告、AIR/个人/公共三类快捷模板和 15 条 PACS 公共模板数据，以及患者查询、分类模板搜索与插入、AIR 报告手动编辑、所见/诊断关联高亮与非对称删除、一键阴性模板、撤销/重做、重新生成、生成失败后重试、整理报告、查看原始报告等演示交互。

AIR 与 PACS 报告编辑页支持两条独立路径：

- `返回 PACS 编辑`：返回 PACS 编辑界面并保留 PACS 原报告，不插入当前 AIR 内容。
- `自动进入规则`：打开患者检查时，PACS 报告为空则自动进入 AIR；PACS 已有内容则默认打开 PACS。若 PACS 与 AIR 均为空，将自动生成 AIR 并显示生成中状态。
- `引用到 PACS 报告`：已经手动整理的报告直接写入 PACS；未整理的报告先显示“报告整理中”，完成后自动写入 PACS。整理过程保留医生新增内容，引用不等于正式发布。
- `整理报告`：将影像所见整理为分号分隔的单段文本；诊断意见使用“序号、诊断内容。”逐条换行展示。
- `撤销 / 重做`：支持在报告编辑操作之间往返；重新生成后的报告同样可撤销并重做。
- `快捷模板`：支持 AIR 模板、个人模板和公共模板三个分类页签；AIR 模板保留双列标签卡片样式，个人和公共模板使用列表样式。
- `手动编辑`：点击 AIR 报告中的任一所见或诊断文字即可修改，修改结果按患者保存，并可通过撤销/重做恢复。
- `行内关联删除`：点击诊断意见的删除按钮后，在当前诊断下方选择仅删除诊断或同步删除对应影像所见；取消操作不会产生编辑历史。
- `AIR 模型切换`：头胸联合检查患者可在颅脑 CT 与胸部 CT AIR 基础模型间切换，两套报告草稿分别保存、互不覆盖。
- `重新生成 / 重试生成`：可主动重新生成当前患者的 AIR 报告；患者“钱*芳”预置为生成失败示例，可从失败提示区或底部按钮重试。
- PACS 顶部 `AI 诊断`：返回当前检查的 AIR 报告并恢复工作草稿。

页面以 1619 × 971 原始界面稿为基准自动等比适配浏览器视口，浏览器保持 100% 缩放即可完整展示全部区域。
